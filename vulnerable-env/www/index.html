ACW3 Target Site (Group P1-6)

Deliberately vulnerable mock environment for the ACW3 pentest demo. Backed by Apache HTTP Server 2.4.68 (fixed in 2.4.69), run only on an isolated lab network / VM. Not for production use, and never expose these ports to the internet.

This page is a map of what to test, not an exploit tool. Identification and exploitation steps are worked out by the team from each official CVE record, per the assignment spec.

Access notes

  • /dav/ requires HTTP Digest auth. Credentials are set up locally per vulnerable-env/README.md (default lab user: labuser, realm acw3-dav) — not published here.
  • /proxy/ forwards to the internal backend service; see backend/server.py for the response parameters it accepts (content type, charset, transfer-encoding) while probing for the mod_xml2enc trigger condition.
