About the portal

About Fieldstone Docs

Fieldstone Docs is the team's internal portal for keeping working documents in one place, sharing them over a secured drive, and reading a mirrored copy of a public news feed. It runs on the team's own server and is reachable only from inside the network.

What's here

  • Shared drive: a workspace at /dav/ where the team reads, uploads, edits, and removes documents. It is protected by a per-user sign-in (HTTP Digest, realm acw3-dav).
  • News mirror: a read-only copy of a public news feed at /proxy/, refreshed on a schedule so the team can scan headlines without leaving the portal.

Access

The shared drive asks you to sign in before it opens. The default account for this environment is labuser in the acw3-dav realm; the password is handed out with the environment setup rather than published here.

Who runs it

This site is built and maintained by Group P1-6 for INF2005 (Cyber Security Fundamentals). It is a lab environment: all content is sample data, and it should only ever run on an isolated VM or lab network, never exposed to the public internet.
