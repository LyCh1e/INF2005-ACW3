About this portal

Fieldstone Docs is the small internal portal our team uses to share files and read a mirrored copy of a public news feed. It runs on an Apache httpd 2.4.68 box in the lab and is only reachable from inside the lab network.

What's here

  • Shared drive at /dav/ — a WebDAV share where team members can read, upload, edit, and delete files. It requires HTTP Digest authentication (realm acw3-dav).
  • News mirror at /proxy/ — a reverse proxy to a small backend service. The backend accepts a few query parameters so we can shape the response (declared vs. actual charset, truncation, transfer-encoding) while we debug a rendering issue with the proxy-html output filter.

Credentials

The default lab user is labuser in the realm acw3-dav. The password is set per the quick-start steps in vulnerable-env/README.md and is not published on this page.

Contact

This is the ACW3 target site maintained by Group P1-6 of INF2005 (Cyber Security Fundamentals). For questions about the lab setup, ask on the team channel; for anything about the course, see the module page on xSite.
